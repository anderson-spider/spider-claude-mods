# secrets

Usage/privacy: [README.md](README.md).
- `hooks/register.tsx`: the one `request_secret` tool's literal `session.start` registration (`inputSchema ... satisfies SchemaFor<McpToolInputs[...]>`: tsc fails when the schema's properties, `required`, `type`/`items` differ from `types/index.d.ts`; descriptions are unchecked), its `tool.call` hook (queues the request, opens the pane, answers at once: it never waits for the user), the card (`card`, drawn by the `Pane` and `AbovePrompt` `ui.render` hooks), `answer` (saves on stdin or declines, then sends the model a `$.prompt.submit` message), the fence `tool.call` hook, the `session.append` and `session.send` scrubbers and `refresh` (deletes expired files, rebuilds the scrubber's index; at session start and hourly). `$` goes only to these top-level functions of the file. `hooks/schema.ts`: the shared `SchemaFor` and `allOf`, a byte-for-byte copy of the template's that `scripts/check-consistency.mjs` enforces, with its type cases in `tests/schema-types.ts`.
- Pure modules, `$` never passed in: `hooks/store.ts` (folder, file names, the 24 hour expiry, the write script: umask 077, `set -C`, the value on stdin and never in argv), `hooks/guard.ts` (the fence: `bashReason`, which also refuses a recursive search from a folder above the secrets folder, as `ancestors` lists them, since some builds have no Grep or Glob tool and search through Bash; `toolReason`, for the file tools and for Grep and Glob where a build has them), `hooks/scrub.ts` (the index and `scrubBlock`), `hooks/request.ts` (input checks, the queue, every message Claude receives). State contract: `types/index.d.ts` (`secrets.requests`, `secrets.isWaiting`).
- Tests mirror modules: `tests/store.test.ts`, `tests/guard.test.ts`, `tests/scrub.test.ts`, `tests/request.test.ts`, `tests/register.test.ts` (`the value pasted in the card goes to a private file on stdin and Claude is sent its path`, `the fence refuses the model's own tools in the folder and allows a file used inside a command`, `the scrubber replaces a saved value in any row before it is stored, including after a restart`). `tests/host.ts`: the host fake (`world`, `started`) with an in-memory secrets folder that host tests share.
- The value is on screen in the paste field (the engine's `Input` has no mask) and in the plugin's memory (the scrubber's index), nowhere else: not in argv, a prompt, a toast or a message to Claude. A change that puts it in any of those breaks the plugin's one promise; `tests/register.test.ts` checks argv and the messages.
- The fence's hooks fail open (the engine skips a hook that throws), so the scrubber is the guarantee: keep it free of anything that can throw.
- Checks: [root commands](../../AGENTS.md#commands).
